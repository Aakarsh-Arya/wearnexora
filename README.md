NEXORA — Static website

This repository contains the static site for NEXORA (wearnexora.in).

Included files (essential):
- index.html
- styles.css
- scripts.js
- Images/Nexora_logo.png

How to use:
1. Serve locally: open `index.html` in a browser or use a static server (e.g., `npx serve`).
2. To push to GitHub:
   - Create a repo on GitHub
   - Follow the commands provided in the next section to push your initial commit.

Notes:
- This repo intentionally keeps only essential files committed by default.
- For production, keep secrets like API keys out of the repo.
